# AI 小车驾驶(AI 开车游戏 · 网页版)

模仿 [bones-ai/rust-drive-ai](https://github.com/bones-ai/rust-drive-ai)(神经网络 + 遗传算法自学开车)的网页版实现。

> 部署于 GitHub Pages,可直接分享链接给任何人玩。

## 如何运行

不需要安装任何东西:直接用浏览器打开 `index.html` 即可。

## 操作说明

| 按键 | 功能 |
| --- | --- |
| ← → / A D | 左右变道 |
| ↑ / W | 加速 |
| ↓ / S | 刹车 |
| T | 切换 AI 代驾(游戏中) |
| R | 重新开始(训练模式中为重新训练) |
| Esc / P | 暂停(训练模式中为返回菜单) |

训练模式中按 **1 / 2 / 4 / 8** 切换模拟加速倍率。触屏设备会自动显示虚拟按钮。

## 三种玩法模式

1. **手动模式**:玩家亲自驾驶,躲避车流,刷分
2. **训练模式**(主菜单「训练模式」):60 辆 AI 车同屏行驶,每辆车用自己的神经网络躲避;
   全部撞毁后按存活距离结算适应度 → 遗传算法产生下一代 → 重新出发。
   黄色射线是当前领先车的「眼睛」(5 条传感器射线),右上角是进化曲线
3. **AI 代驾模式**(游戏中按 T):让最佳网络接管驾驶,实时画出传感器射线。
   优先使用训练模式产出的网络;没有训练过则使用内置「出厂 AI」。
   菜单里可**导出**当前网络为 JSON(Python 离线训练的 `best_net.json` 也能**导入**)

## AI 是怎么学会开车的(答辩要点)

- **神经网络**:7 输入(5 条传感器射线 + 速度 + 横向位置)→ 12 隐层(tanh)→ 2 输出(转向、油门)
- **遗传算法**:种群 60~100、锦标赛选择(k=3)、均匀交叉、高斯变异、精英保留
- **适应度**:存活距离(像素)
- **训练曲线**:`output/training_curve.png`(离线训练生成,蓝色 = 最佳,橙色 = 平均)

## 项目结构

```
ai小车/
├── index.html          # 入口页面
├── css/style.css       # 页面样式
├── js/
│   ├── config.js       # 全部可调参数(仿原版 src/configs.rs)
│   ├── utils.js        # 工具函数
│   ├── nn.js           # 手写神经网络(前向传播/变异/交叉/JSON 序列化)
│   ├── ga.js           # 遗传算法(锦标赛选择/精英保留/停滞自适应变异)
│   ├── road.js         # 道路渲染
│   ├── cars.js         # 车辆实体与绘制
│   ├── sensors.js      # 射线传感器(5 条扇形射线探测前方车辆)
│   ├── game.js         # 游戏世界(状态机/生成/碰撞/计分)
│   ├── train.js        # 训练模式(种群同屏进化 + 曲线)
│   ├── preset-net.js   # 内置“出厂 AI”(tools/train-sim.js 训练生成)
│   ├── ui.js           # HUD 与界面覆盖层
│   └── main.js         # 入口与主循环
├── python/             # Python 版实现(离线实验/训练曲线/论文图表)
│   ├── nn.py           # 神经网络(与 js/nn.js 逐层一致)
│   ├── ga.py           # 遗传算法(与 js/ga.js 一致)
│   ├── driving_env.py  # 5 车道避障训练环境(与 tools/ai-bench.js 一致)
│   ├── train.py        # 训练脚本 + matplotlib 曲线
│   └── README.md       # 安装与使用说明
├── tools/              # Node 开发工具(不需要打包,浏览器直接运行游戏)
│   ├── ai-bench.js     # 离线训练基准(训练 + JSON 导入复测)
│   ├── train-sim.js    # 训练模式无渲染模拟(验证进化有效)
│   ├── nn-test.js      # 神经网络单元测试
│   └── smoke-test.js   # 冒烟测试(全部脚本加载 + 核心流程)
└── output/
    ├── best_net.json         # 训练好的最佳网络(JS 与 Python 通用格式)
    ├── best_net_js.json      # JS 离线训练产出的最佳网络
    └── training_curve.png    # Python 训练曲线(适合写进课程报告)
```
